# Turing Machine Exercise

## Description

This project contains an implementation of a **Turing Machine** as part of a theoretical computer science exercise.

The program simulates the operation of a Turing Machine by reading an input string, applying transition rules, and determining whether the input is **accepted or rejected**.

## Features

* Simulates a single-tape Turing Machine
* Reads an input string from the user
* Applies transition rules step by step
* Moves the tape head left or right
* Displays the machine's execution
* Determines whether the input is accepted or rejected

## How It Works

A Turing Machine consists of:

* **States** – represent the current state of the machine
* **Tape** – stores the input and intermediate symbols
* **Head** – reads and writes symbols on the tape
* **Transition function** – determines the next action
* **Accept state** – indicates successful completion
* **Reject state** – indicates that the input is not accepted

The machine repeatedly applies its transition rules until it reaches an accept or reject state.

## Technologies

* Programming Language: Python


## Exercise

The purpose of this exercise is to understand how Turing Machines work and how their theoretical model can be represented programmatically.
